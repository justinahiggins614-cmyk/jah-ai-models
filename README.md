# The AI Telephone Book — home of every AI

Live: https://justinahiggins614-cmyk.github.io/jah-ai-models/

Every AI lives here as a file. Each file carries its mentality, abilities, data —
and a working demo you can run, talk to, and download. Single self-contained
`index.html` (no build step, no external assets except the standard TTS audio
endpoints). Pure hand-written JavaScript — no `eval()` anywhere.

## Wings

1. **Signature AI Systems** — the 10 core minds of the JAH system + Hybrid Fusion:
   Deterministic, Probabilistic, Geometric (six-tool), Hash, Neural, Evolutionary,
   Fuzzy, Swarm, Decision-Tree, Cellular-Automata, Hybrid Fusion. Each file: dossier,
   working interactive demo, 🔊 read-aloud, ⧉ copy, ⤓ download of its real working
   `.py` implementation, Signature-made badge + link to the Spec Catalog.
2. **Persona Archive** — Darth Vader, Ultron, Voltron, J.A.R.V.I.S., T-800
   Terminator, Skynet. Each: persona dossier, AI dialog chat in its own
   voice/mentality (rule-based persona engine), per-persona TTS pitch/rate,
   themed working mini-demo, read-aloud/copy/download. Marked "Persona simulation
   — fan-style interpretation, not affiliated with any rights holder."
3. **Signature Domain AIs — every need** — data-driven: each AI is a compact spec
   in `DOMAIN_SPECS` (id, name, domain, mentality, abilities, demo kind, honesty
   flag) and the page renders a full file from it: dossier, themed working demo
   (6 reusable templates: chat, planner, quiz, calc, picker, checklist), dialog
   chat, read-aloud, copy, generated `.py` download. Counseling/medical/legal/
   financial-adjacent AIs carry a one-line "AI assistant, not a licensed
   professional" note. New specs plug in boundlessly behind the same page.
4. **Telephone Directory** — searchable A–Z listing of EVERY AI: all systems,
   personas, domain AIs, mix-lab hybrids, plus the AI families on the six sister
   sites (Patent AI, Spec AI, Word AI Teacher, Article AI, Dossier AI,
   Calculator AI) deep-linked to where they live.
5. **Mix Lab** — pick any two AIs → named hybrid with merged mentality, working
   fused demo, downloadable hybrid `.py`.
6. **Incoming Transmissions** — the archive grows; new files plug in here.

## Audio

Tiered TTS everywhere: speechSynthesis (female English voice preferred) →
ResponsiveVoice → 2 Google TTS hosts, chunked, with stop + speed control.
Dialog replies auto-read with a per-file mute toggle; personas use their own
pitch/rate (Vader slow/deep 0.7, Jarvis crisp 1.05, Ultron cold 0.9, Skynet flat
0.85, T-800 terse 0.8, Voltron heroic 1.0).

Part of THE JAH NETWORK — all seven sites link each other.
